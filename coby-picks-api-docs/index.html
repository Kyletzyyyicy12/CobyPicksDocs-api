API authorization

Paste a Firebase Authentication ID token to send it as Authorization: Bearer <token> with API requests. Admin endpoints check the account’s role and may also require a verified admin sign-in code.

Use a real token from a Coby Picks sign-in. There are no simulated role presets. The token stays in this page’s memory and is not saved to browser storage.
